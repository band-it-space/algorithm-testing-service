## Methodology

### Test Setup
- **Stock universe**: 30 Hong Kong stocks
- **Period**: March 2009 – March 2019
- **Original**: Signals generated by the production API (original algorithm, StockFisher API)
- **Optimized**: Signals generated by the optimized algorithm (same logic, same data source, precomputed indicators)
- **Genome**: G_000 (default parameters — no optimization applied, pure algorithm comparison)

### Comparison Process
1. Both systems processed the same 30 stocks for the same date range
2. Trades were matched by stock code + entry date
3. Each matched trade was compared on: entry date, entry price, exit date, exit price, profit %, direction

## Bug Fix Applied

One calculation bug was identified and fixed to achieve this accuracy:

**S1 Stop Loss `hard_stop` threshold**: Default was `0.095` (9.5%), should be `0.30` (30%)

- **Impact**: With the wrong threshold, almost every stock triggered the high-stop tier (14.25%) when it should have used the base stop or medium stop (9.5%), fundamentally changing stop-loss placement
- **Files fixed**: `algorithm_models.py` (default value), `precomputed_indicators.py` (getattr fallbacks)
- **Result**: Fix restored perfect sell signal accuracy from 88.5% to 100%
